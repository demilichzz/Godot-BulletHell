Project-Structure

范围与阅读约定
- 按“目录 → C# 文件 → 类型及描述”展示；嵌套类型列在所属类型下。
- 类型描述取自当前源码的 XML summary 注释；缺失时标记“缺少类型描述”，不推测补写。
- 目录描述根据当前文件内容归纳，仅说明已存在的内容，不代表未来规划。
- 资源只列目录及内容描述，不列具体文件；包括图片、字体、Godot 场景和 .tres 配置资源。
- 不展开 .uid、.import 辅助文件；不收录 .git、.godot、.tools、构建输出和本地临时目录。
- 根目录保留项目配置和文档文件，便于定位入口与开发约定。

BulletHell/ — Godot .NET / C# 2D Boss 挑战项目；根目录含常驻游戏入口和战场场景资源。
├── Assets/ — 美术与字体资源，按弹幕、界面和单位分类。
│   ├── fonts/ — 界面及 HUD 使用的字体资源。
│   │   ├── fusion_pixel/ — 支持简体中文的 Fusion Pixel 像素字体。
│   │   └── lxgl/ — 霞鹜文楷屏幕阅读字体，供战斗 HUD 使用。
│   ├── Sprites/ — 圆形、鳞形、水滴及星形弹幕十色图集，每格16×16像素。
│   ├── UI/ — 战斗区域的界面背景图片。
│   └── Units/ — Boss_01～05的四帧透明动画图集，均为2×2布局、每帧64×64像素；未配置的素材不进入正式目录。
├── Boss/ — Boss 配置类型、展示目录、实例工厂、控制器与阶段行为。
│   ├── Boss.cs
│   │   └── Boss：旧版 Boss 兼容入口，普通弹幕容器下自行驱动新控制器。
│   ├── BossCatalog.cs
│   │   └── BossCatalog：保存 Boss 的展示顺序，并按唯一标识查询。
│   ├── BossController.cs
│   │   └── BossController：管理 Boss 生命、图集动画、碰撞轮廓与顺序阶段，支持切换相邻阶段，默认由战斗管理器更新。
│   ├── BossData.cs
│   │   └── BossData：保存单个 Boss 的静态配置，可在编辑器中创建独立资源。
│   ├── BossFactory.cs
│   │   └── BossFactory：从独立配置生成控制器和全新阶段，供挑战与重开共用。
│   └── BossPhase/ — 阶段抽象基类及按Boss组织的专属阶段、发射批次。
│       ├── BossPhase.cs
│       │   └── BossPhase：管理Boss阶段的移动、初始生命、活动批次及阶段计时器。
│       ├── Boss_01/ — Boss_01的三个独立阶段、固定或圆周目标移动及六个发射器。
│       │   ├── B01_Phase01.cs
│       │   │   └── B01_Phase01：调度Boss_01阶段01的双发射器和圆周目标移动。
│       │   ├── B01_Phase02.cs
│       │   │   └── B01_Phase02：调度Boss_01阶段02的发射器和固定目标移动。
│       │   ├── B01_Phase03.cs
│       │   │   └── B01_Phase03：调度Boss_01阶段03的斜线逐圈发射和圆周目标移动。
│       │   ├── B01P01_Emitter01.cs
│       │   │   └── B01P01_Emitter01：为Boss_01阶段01的发射器01构造一次24颗等角环形弹幕。
│       │   ├── B01P01_Emitter02.cs
│       │   │   └── B01P01_Emitter02：为Boss_01阶段01的发射器02构造一次16颗等角环形弹幕，并覆盖速度与颜色。
│       │   ├── B01P02_Emitter01.cs
│       │   │   └── B01P02_Emitter01：在六个随机圆心分别构造12颗等角环形弹幕。
│       │   ├── B01P02_Emitter02.cs
│       │   │   └── B01P02_Emitter02：为Boss_01阶段02的发射器02构造一次24颗等角环形弹幕。
│       │   ├── B01P03_Emitter01.cs
│       │   │   └── B01P03_Emitter01：沿Boss下方斜线依次生成六圈敌弹，并为每圈设置延迟追踪。
│       │   └── B01P03_Emitter02.cs
│       │       └── B01P03_Emitter02：为Boss_01阶段03的发射器02构造一次24颗等角环形弹幕。
│       ├── Boss_02/ — Boss_02的基础阶段与空发射器。
│       │   ├── B02_Phase01.cs
│       │   │   └── B02_Phase01：Boss_02的唯一阶段，沿用基类移动且暂不发射弹幕。
│       │   └── B02P01_Emitter01.cs
│       │       └── B02P01_Emitter01：Boss_02阶段01的空发射器，暂不生成弹幕。
│       ├── Boss_03/ — Boss_03的基础阶段与空发射器。
│       │   ├── B03_Phase01.cs
│       │   │   └── B03_Phase01：Boss_03的唯一阶段，沿用基类移动且暂不发射弹幕。
│       │   └── B03P01_Emitter01.cs
│       │       └── B03P01_Emitter01：Boss_03阶段01的空发射器，暂不生成弹幕。
│       ├── Boss_04/ — Boss_04的基础阶段与空发射器。
│       │   ├── B04_Phase01.cs
│       │   │   └── B04_Phase01：Boss_04的唯一阶段，沿用基类移动且暂不发射弹幕。
│       │   └── B04P01_Emitter01.cs
│       │       └── B04P01_Emitter01：Boss_04阶段01的空发射器，暂不生成弹幕。
│       └── Boss_05/ — Boss_05的基础阶段与空发射器。
│           ├── B05_Phase01.cs
│           │   └── B05_Phase01：Boss_05的唯一阶段，沿用基类移动且暂不发射弹幕。
│           └── B05P01_Emitter01.cs
│               └── B05P01_Emitter01：Boss_05阶段01的空发射器，暂不生成弹幕。
├── Bullet/ — 子弹状态、枚举默认参数集、单次发射批次、可选方向排列、运动行为及生命周期管理。
│   ├── Bullet.cs
│   │   └── Bullet：保存弹幕状态与外观，由管理器统一推进和释放。
│   ├── BulletBehavior.cs
│   │   ├── BulletBehavior：描述弹幕生成后的运动规则；无状态实例可共享。
│   │   └── StraightBehavior：按当前速度进行直线运动。
│   ├── BulletDefaultSet.cs
│   │   ├── BulletType [枚举]：选择一整组弹幕基础参数，成员统一以Set结尾。
│   │   └── BulletDefaultSet [记录类]：集中保存不可变的弹幕完整初始化参数与默认预设。
│   ├── BulletEmitter.cs
│   │   ├── BulletTeam [枚举]：弹幕所属阵营，用于筛选伤害目标。
│   │   ├── BulletEmitter：构造单次发射批次并保存仍有效的子弹引用，不负责时序或运动。
│   │   └── SingleBulletEmitter：按完整参数构造单颗子弹的发射批次。
│   ├── BulletManager.cs
│   │   └── BulletManager：统一推进弹幕与碰撞，释放时注销批次和目标关联。
│   └── BulletPattern.cs
│       ├── BulletPattern：可选的弹幕方向排列工具，不负责创建子弹或控制发射时序。
│       ├── SinglePattern：沿指定初始方向输出单颗子弹角度。
│       └── AngularPattern：从单一起点按固定角度间隔排列方向，支持圆环、扇形和单发。
├── Core/ — 常驻游戏管理、单场战斗推进、通用参数与默认输入绑定。
│   ├── BattleConfig.cs
│   │   └── BattleConfig：集中保存场地、角色与全场弹幕容量参数；位置为像素，时间为秒。
│   ├── GlobalEvent.cs
│   │   ├── GlobalEvent：提供当前战斗实体、弹幕管理器及计时器注册的全局入口。
│   │   └── GlobalEvent.Scope：管理初始化、清理和固定步推进期间的临时战斗上下文。
│   ├── BattleManager.cs
│   │   ├── BattleState [枚举]：单场战斗的运行与结束状态。
│   │   └── BattleManager：以60Hz固定步和计时事件分段驱动战斗，管理种子、结束与重开。
│   ├── GameInput.cs
│   │   └── GameInput：注册全游戏默认动作及战斗Q/E阶段切换，保留用户已有的同名映射。
│   └── GameManager.cs
│       └── GameManager：常驻游戏根管理器，通过注册表延迟替换唯一活动 Stage。
├── Data/ — Godot 数据配置资源；根层保存Boss_01～05的正式展示目录。
│   └── Bosses/ — Boss_01～05各自的属性、贴图引用、动画参数与阶段配置资源。
├── Math/ — 统一弧度的坐标数学与随机数工具，为战斗重现提供统一随机入口。
│   └── VMath.cs
│       ├── RandomDiffMode [枚举]：指定随机偏移区间从零起算或以零为中心。
│       └── VMath：提供统一弧度的坐标数学工具及固定算法的可重现随机序列。
├── Player/ — 玩家控制器及移动、闪避、生命、自动攻击组件。
│   ├── PlayerAttack.cs
│   │   └── PlayerAttack：通过重复计时器瞄准Boss当前中心，逐次创建单发批次。
│   ├── PlayerController.cs
│   │   └── PlayerController：协调玩家运动、闪避、生命与自动攻击，由战斗管理器驱动。
│   ├── PlayerDodge.cs
│   │   └── PlayerDodge：使用战斗计时器管理闪避方向、持续时间与冷却。
│   ├── PlayerHealth.cs
│   │   └── PlayerHealth：管理可降至负数的玩家生命及由战斗计时器结束的受击无敌。
│   └── PlayerMovement.cs
│       └── PlayerMovement：计算玩家移动与战场边界约束。
├── Stage/ — 场景生命周期与进入参数、Boss 选择及战斗 Stage；含对应的场景资源。
│   ├── BattleStage.cs
│   │   └── BattleStage：通用 Boss 战斗场景，装配战场并在离场时停止战斗。
│   ├── BossSelectStage.cs
│   │   └── BossSelectStage：Boss 选择场景，负责目录展示及发出战斗切换请求。
│   └── Stage.cs
│       ├── StageContext：一次场景进入所需的参数，独立于场景节点生命周期。
│       └── Stage：游戏内场景的统一生命周期；同一时刻只激活一个实例。
├── Tests/ — 战斗回归、计时器边界、随机移动重现与 Stage 集成验证代码及验证场景资源；测试类型不属于正式 Boss 内容。
│   ├── BattleVerification.cs
│   │   └── BattleVerification：独立运行的战斗回归验证节点，不进入正式游戏场景。
│   │       └── ProbePhase [嵌套类]：记录阶段生命周期调用次数的测试实现。
│   ├── DeterminismVerification.cs
│   │   └── DeterminismVerification：验证弧度坐标工具、固定随机序列、Boss圆周移动时序及相同输入下的战斗重现。
│   ├── StageVerification.cs
│   │   └── StageVerification：验证场景切换、独立 Boss 配置和选择界面的集成行为。
│   │       └── ProbeStage [嵌套类]：验证注册扩展和生命周期次数的测试场景。
│   ├── TimerVerification.cs
│   │   └── TimerVerification：验证计时器边界、目标注销、分段运动及固定输入重现。
│   └── VerificationClock.cs
│       └── VerificationClock：为隔离验证提供固定战斗步及事件分段推进辅助。
├── Timer/ — 毫秒计时器、整数逻辑时钟、稳定事件调度和目标生命周期关联。
│   ├── VTimer.cs
│   │   ├── VTimerType [枚举]：定义单次、有限重复及永久重复计时器。
│   │   ├── VTimerState [枚举]：记录计时器从创建到完成或取消的状态。
│   │   └── VTimer：保存毫秒配置，支持无目标回调或绑定存活节点的回调。
│   └── VTimerProcessor.cs
│       └── VTimerProcessor：按整数逻辑时间稳定调度计时器，并管理目标生命周期关联。
├── UI/ — Boss 选择网格与单项展示控件。
│   ├── BossSelectItem.cs
│   │   └── BossSelectItem：展示一个 Boss 的图片和名称，点击仅改变选择。
│   └── BossSelectUI.cs
│       └── BossSelectUI：以四列网格展示目录，统一管理鼠标选择、方向导航和空格确认。
├── .gitignore — Git 忽略规则。
├── AGENTS.md — 项目开发约定与本文档的同步维护规则。
├── BulletHell.csproj — Godot .NET SDK、C# 目标框架及构建配置。
├── Main.cs
│   └── Main：组装当前战场、活动区域轮廓、键盘操作和显示阶段及Q/E提示的简易中文状态显示。
├── project.godot — Godot 项目、启动场景、窗口与渲染配置。
├── Project-Structure.txt — 项目目录、代码类型及资源目录内容索引。
└── README.md — 运行操作、玩法参数、模块扩展与验证说明。
