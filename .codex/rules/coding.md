# C# 开发规则

## 命名

- 具体阶段类使用 `B{Boss编号}_Phase{阶段编号}`，例如 `B01_Phase01`；具体发射器类使用 `B{Boss编号}P{阶段编号}_Emitter{发射器编号}`，例如 `B01P01_Emitter01`。
- 编号至少两位，不足补零；新增同类沿用此规则，文件名与类名一致，通用基类保留原名。

## with 表达式

多属性初始化器的左右花括号各自换行，每个属性赋值单独一行，结束花括号后的调用括号沿用下例；生产代码和测试代码均适用。空初始化器或单属性初始化器可保留单行。

```csharp
AddBullet(manager, settings with
{
    Position = owner.GlobalPosition,
    Speed = 240
});
```

## 中文注释

- 新增或修改的 C# 代码保持简短、准确的中文注释；每个类、方法（含构造函数和 Godot override 回调）、属性使用 XML `summary` 说明用途。
- 每个参数使用 XML `param`，有返回值时使用 `returns`。说明含义及适用的单位、方向、范围和默认值；时间、角度、位置、速度、图集索引及显示倍率须明确单位和约定。
- 每个字段、常量、局部变量和循环变量均简要说明用途；相关变量可在声明附近合并注释。
- 行为、单位、范围或默认值变化时同步更新注释；说明用途和必要约定，不逐行复述语法。Godot/.NET 自动生成文件及第三方代码除外。
- 仅补注释时保留现有逻辑和用户调整的参数，不引入额外功能。
